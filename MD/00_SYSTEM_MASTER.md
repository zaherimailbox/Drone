## ۴. قرارداد مرزی مشترک (Interface Contract)

### ۴.۱. قرارداد بسته فرمان وب‌اپلیکیشن به سرور Go (از طریق WebSocket)
```json
{
  "target": "tx_controller",
  "mode": "manual",          // "manual" | "auto"
  "frequency_hz": 12000,     // 5000 to 15000
  "duty_cycle": 0.25,        // 0.05 to 0.90
  "auto_sweep": {
    "start_freq": 5000,
    "end_freq": 15000,
    "step_hz": 1000,
    "interval_sec": 3
  }
}
```

### ۴.۲. قرارداد بسته تله‌متری سرور Go به وب‌اپلیکیشن
```json
{
  "timestamp": 1700000000123,
  "telemetry": {
    "flight": {
      "altitude_agl_cm": 35.2,   // فاصله از زمین بر اساس لیدار
      "gps_lat": 35.6892,
      "gps_lon": 51.3890
    },
    "metal_detector": {
      "active_freq": 12000,
      "duty_cycle": 0.25,
      "signal_amplitude_mv": 142.8,
      "signal_phase_deg": 41.5,
      "estimated_depth_cm": 28.4,
      "target_detected": true
    }
  }
}
```

## ۵. قانون طلایی عدم تناقض (Conflict Prevention Rule)
1. هیچ سندی نباید فرضی مغایر با ولتاژها، پورت‌های ارتباطی یا پروتکل‌های مشخص‌شده در این فایل داشته باشد.
2. هرگاه تغییری در مشخصات سخت‌افزاری (مثلاً تغییر پین‌ها، تغییر سطح ولتاژ، یا تغییر نرخ باود ریت) پیش بیاید، **ابتدا این فایل آپدیت شده و نسخه آن ارتقا می‌یابد**، سپس در سند مربوطه اعمال می‌شود.
