## ۲. دیاگرام نهایی جریان سیگنال و داده (End-to-End Pipeline)

```text
[Raspberry Pi 5 (لینوکس و سرور Go)]
   │  (تغذیه 5V + گذرگاه پرسرعت SPI1 @ 20MHz + وقفه سخت‌افزاری IRQ)
   ▼
[WeAct Studio Black Pill — STM32G431CBU6 (170MHz)]
   │
   ├── [مسیر رفت قدرت - TX Path]:
   │   (پین PA8 / TIM1_CH1) ──► [درایور ایزوله UCC21520] (تغذیه از B1212S-2W)
   │                                   │
   │                                   ▼ (پالس 12V گیت)
   │                       [ماسفت STW45NM60 + کلمپ 1.5KE400A TVS]
   │                                   │
   │                                   ▼ (سوئیچینگ جریان 3 آمپری)
   │                       [کویل 350µH موازی مقاومت 560Ω 5W]
   │                                   │
   │                                   ▼ (نقطه درین مشترک - Drain Node)
   │
   └── [مسیر برگشت حساس - RX Path]:
       [مقاومت محدودکننده 2.2kΩ 3W + جفت دیود شاتکی 1N5819 به GND]
                                       │
       (پین PA9 / TIM1_CH2) ──► [سوئیچ بلنکینگ فوق‌سریع TS5A3159 SPDT]
                                       │ (باز شدن در لحظه t = 110µs)
                                       ▼
                         [آپ‌امپ OPA365 با بایاس +0.20V] (Gain = 20-50)
                                       │
                         [شبکه فیلتر و محافظ 100Ω + BAT54S + 100pF]
                                       │
                                       ▼
       (پین PA0 / ADC1_IN1) ◄── [نمونه‌برداری 4MSPS سخت‌افزاری با DMA]
```

## ۳. جدول کامل نگاشت پین‌ها و کانکتورها (Pinout & Wiring Matrix)

### ۳.۱. درگاه ارتباط با Raspberry Pi 5 (اتصال به هدر ۴۰ پین)
تغذیه بلک‌پیل مستقیماً از ریل ۵ ولت رزبری تامین شده و رگولاتور روی برد بلک‌پیل (`ME6211`) ولتاژ تمیز ۳.۳ ولت را برای هسته و بخش آنالوگ تولید می‌کند:

| عملکرد خط | پین Raspberry Pi 5 | پین STM32G431 (Black Pill) | سطح ولتاژ | توضیح فنی |
| :--- | :--- | :--- | :---: | :--- |
| **تغذیه ۵ ولت** | Pin `2` یا `4` (`+5V`) | `5V` | $5.0\text{V}$ | ورودی رگولاتور LDO روی برد میکروکنترلر |
| **زمین دیجیتال** | Pin `6` (`GND`) | `G` | $0\text{V}$ | مرجع زمین مشترک داده و فرمان (`GND_DIG`) |
| **SPI MOSI** | Pin `19` (`GPIO10`) | `PA7` (`SPI1_MOSI`) | $3.3\text{V}$ | ارسال پارامترهای عرض پالس، فرکانس و تاخیر بلنک |
| **SPI MISO** | Pin `21` (`GPIO9`) | `PA6` (`SPI1_MISO`) | $3.3\text{V}$ | استریم بافر ۱۲۸ نمونه‌ای ADC به رزبری‌پای |
| **SPI SCLK** | Pin `23` (`GPIO11`) | `PA5` (`SPI1_SCK`) | $3.3\text{V}$ | کلاک گذرگاه SPI (تا فرکانس ۲۰ مگاهرتز) |
| **SPI CS** | Pin `24` (`GPIO8`) | `PA4` (`SPI1_NSS`) | $3.3\text{V}$ | فعال‌ساز تراشه Slave |
| **وقفه آماده‌باش (IRQ)** | Pin `22` (`GPIO25`) | `PB0` (`GPIO_Output`) | $3.3\text{V}$ | پالس وقفه اعلام پایان انتقال بافر DMA |

### ۳.۲. درگاه طبقه قدرت فرستنده (TX Gate & Power Stage)

| عملکرد سیگنال | پین STM32G431 | پین درایور / مدار قدرت | پارت‌نامبر قطعه | مشخصات و نقش در مدار |
| :--- | :--- | :--- | :--- | :--- |
| **فرمان پالس گیت** | `PA8` (`TIM1_CH1`) | ورودی `INA` درایور | `UCC21520` | پالس ۳.۳ ولتی PWM با رزولوشن ۵.۹ نانوثانیه‌ای |
| **تغذیه اولیه درایور** | `3V3` و `G` | `VCCI` و `GNDI` | `UCC21520` | تغذیه سمت منطقی درایور |
| **تغذیه ثانویه ایزوله** | - | `VDDA` و `VSSA` | `B1212S-2W` | مبدل ۱۲ ولت ایزوله + خازن‌های ۱۰ میکرو و ۱۰۰ نانوفاراد |
| **خروجی گیت ماسفت** | - | خروجی `OUTA` | مقاومت $15\Omega / 0.5\text{W}$ | شارژ و دشارژ سریع خازن گیت ماسفت ($4\text{A}$ پیک) |
| **پول‌داون ایمنی گیت** | - | بین Gate و Source | مقاومت $10\text{k}\Omega$ | تضمین خاموش بودن ماسفت هنگام بوت یا قطعی سیم |
| **سوئیچ قدرت** | - | گیت، درین و سورس | `STW45NM60` | ماسفت ۶۰۰ ولتی با $R_{DS(on)} = 90\text{ m}\Omega$ روی هیت‌سینک |
| **کلمپ اضافه ولتاژ** | - | موازی Drain-Source | `1.5KE400A TVS` | قفل کردن قطعی اسپایک ولتاژ روی $400\text{V}$ |
| **میراگر تانک کویل** | - | موازی دو سر کویل | $560\Omega / 5\text{W}$ | مقاومت بدون اندوکتانس جهت میرایی بحرانی ($R_{damping}$) |

### ۳.۳. درگاه طبقه دریافت آنالوگ و بلنکینگ (RX Front-End)

| عملکرد سیگنال | پین مدار آنالوگ | پین STM32G431 | قطعه و مقدار | مشخصات و نقش در مدار |
| :--- | :--- | :--- | :--- | :--- |
| **برش و محدودسازی اولیه** | گره Drain کویل | - | $2.2\text{k}\Omega / 3\text{W}$ + جفت `1N5819` | کاهش ولتاژ ۴۰۰ ولتی و برش در سقف $\pm 0.4\text{V}$ |
| **فرمان بلنکینگ فعال** | کنترل سوئیچ `IN` | `PA9` (`TIM1_CH2`) | `TS5A3159` | اتصال ورودی آپ‌امپ به زمین در طول پالس و میرایی اولیه |
| **تقویت‌کننده پهن‌باند** | ورودی غیرمعکوس `+IN` | - | `OPA365` (تک‌تغذیه) | آپ‌امپ ۵۰ مگاهرتزی با بهره $G=20\text{--}50$ |

| **فیلتر و حفاظت نهایی ADC** | ورودی آنالوگ میکرو | `PA0` (`ADC1_IN1`) | $100\Omega$ + `BAT54S` + $100\text{pF}$ | حفاظت ورودی ADC در برابر ولتاژهای بالای $3.3\text{V}$ |

## ۴. زمان‌بندی سخت‌افزاری نانوثانیه‌ای (Microsecond Timing Diagram)

تایمر سخت‌افزاری `TIM1` میکروکنترلر به صورت خودمختار (Autonomous) بدون دخالت نرم‌افزار، چرخه زیر را در هر تناوب اجرا می‌کند:

```text
1. پالس گیت فرستنده (PA8 / TIM1_CH1):
   ────────────────┐____________________ 100 µs (ON) ____________________┌────────────────────────────────────────────────────────
                   │                                                     │
                   ◄───────────── شارژ جریان کویل تا ~3 آمپر ──────────► ◄── خاموش شدن ماسفت و آغاز ضربه سلفی

2. ولتاژ درین کویل (Drain Spike):
                                                                         ▲ +400V (قفل‌شده توسط دیود 1.5KE400A TVS)
                                                                         │
   ──────────────────────────────────────────────────────────────────────┴───────────╲_ (میرایی کامل ظرف 8 تا 10 میکروثانیه)
                                                                                      ╲

3. کلید بلنکینگ آنالوگ (PA9 / TIM1_CH2):
   ────────────────┐____________________ 110 µs (ورودی آپ‌امپ به زمین وصل است) ____________________┌──────────────────────────────
                   │ (آپ‌امپ در طول پالس و ضربه 400 ولتی کاملاً ایزوله است و اشباع نمی‌شود)          │ (وصل شدن سیگنال کویل در 20ns)
                   │                                                                             │
                   └─────────────────────────────────────────────────────────────────────────────┘
                                                                                                 ▲
4. شروع نمونه‌برداری ADC با DMA:                                                                 │
                                                                                                 └───► ▲▲▲▲▲▲▲▲▲▲▲▲▲▲▲▲ (128 نمونه)
                                                                                                       (ثبت پیوسته منحنی زوال فلز)
```

## ۵. استراتژی زمین ستاره‌ای (Star-Grounding Architecture)

برای تضمین عدم نفوذ نویز جریان‌های پالسی به داخل مبدل آنالوگ:
1. **زمین دیجیتال (`GND_DIG`):** مشترک بین رزبری‌پای ۵، برد بلک‌پیل و سمت ورودی درایور `UCC21520`.
2. **زمین قدرت (`GND_PWR`):** مسیر جریان ۳ آمپری کویل، منبع ۱۲ ولت، سورس ماسفت و خازن‌های بانک `2200µF`.
3. **زمین گیرنده حساس (`GND_RX`):** زمین دیودهای شاتکی، کلید `TS5A3159` و آپ‌امپ `OPA365`.
4. **نقطه اتصال ستاره‌ای (Single Star Point):**  
   زمین‌های `GND_DIG` و `GND_RX` دقیقاً در یک نقطه فیزیکی واحد روی پایه **Source** ماسفت `STW45NM60` و ترمینال منفی خازن بانک قدرت به هم متصل می‌شوند تا حلقه زمین (Ground Loop) شکل نگیرد.
