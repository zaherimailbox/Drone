## ۱. نمای کلی و معماری نرم‌افزاری

سرور Go در نقش هسته پردازشی و مسیریاب ارتباطات (Central Router) عمل می‌کند. این برنامه به عنوان یک سرویس سیستمی (Systemd Service) در محیط لینوکس رزبری‌پای ۵ اجرا می‌شود.

```text
               +---------------------------+
               |     Web Browser (UI)      |
               +---------------------------+
                             │  WebSocket (/ws)
                             ▼
         +───────────────────────────────────────+
         │      Raspberry Pi 5 (Go Server)       │
         │                                       │
         │  ┌───────────────┐ ┌───────────────┐  │
         │  │ WebSocket Hub │ │ Auto-Sweep    │  │
         │  │ & HTTP Server │ │ Ticker Engine │  │
         │  └───────┬───────┘ └───────┬───────┘  │
         │          │                 │          │
         │          ▼                 ▼          │
         │     [ Command Router & Validator ]    │
         │          │                 │          │
         │          ▼                 ▼          │
         │  ┌───────────────┐ ┌───────────────┐  │
         │  │ MAVLink Client│ │ UART / Serial │  │
         │  │ (Pixhawk 6C)  │ │ (STM32 MCU)   │  │
         │  └───────────────┘ └───────────────┘  │
         +───────────────────────────────────────+
```

## ۲. وظایف کلیدی سرور Go

### ۲.۱. وب‌سرور و مدیریت وب‌سوکت
- سرویس‌دهی فایل‌های استاتیک فرانت‌اند (HTML/CSS/JS).
- مدیریت اتصالات همزمان کلاینت‌ها با کتابخانه استاندارد `gorilla/websocket`.
- برادکست کردن وضعیت‌های تله‌متری به کلاینت‌های متصل.

### ۲.۲. موتور زمان‌بندی پویش فرکانسی (Auto-Sweep Ticker)
- هنگامی که مد کاری بر روی `auto` قرار دارد، یک Goroutine با استفاده از `time.NewTicker` فرکانس‌های تعریف‌شده را طبق پریود زمانی مشخص به صورت خودکار به میکروکنترلر ارسال می‌کند.
- امکان توقف فوری (Abort) در صورت ارسال دستور تغییر مد یا فیل‌سیف.

### ۲.۳. درایور سریال (UART Serial Manager)
- ارتباط با پورت `/dev/ttyAMA0` رزبری‌پای با باودریت بالا (مثلاً ۱۱۵۲۰۰ یا ۹۲۱۶۰۰).
- تبدیل داده‌های JSON کلاینت به بسته‌های جمع‌وجور باینری یا فریم‌های سریال ساخت‌یافته جهت ارسال به STM32.
- دریافت پاسخ‌های اندازه‌گیری آنالوگ و سنسور از STM32 و تبدیل آن به آبجکت‌های تله‌متری.

### ۲.۴. امنیت سخت‌افزاری و ایمنی نرم‌افزار (Watchdog & Fail-Safe)
- ارسال پالس Heartbeat به STM32؛ در صورتی که ارتباط قطع شود، STM32 موظف است پالس‌های قدرت کویل را جهت جلوگیری از سوختن ماسفت‌ها سریعاً متوقف کند.
