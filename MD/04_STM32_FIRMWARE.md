## ۱. نقش میکروکنترلر در سیستم

میکروکنترلر لایه‌ی بلادرنگ قطعی (Deterministic Hard Real-Time) سیستم است. لینوکس رزبری‌پای توانایی ساخت پالس‌های با پایداری نانوثانیه‌ای و نمونه‌برداری فوق‌سریع بدون جیتر را ندارد؛ این وظیفه به طور کامل به STM32 محول شده است.

---

## ۲. ساختار ۴ گیت‌وی برد میکروکنترلر (Board Gateway Architecture)

```text
                  ┌──────────────────────────────────────────┐
                  │        GATEWAY 1: NORTH (رزبری‌پای)      │
                  │   UART (DMA) + SPI + IRQ + 5V + GND      │
                  └────────────────────┬─────────────────────┘
                                       │
                                       ▼
                  ┌──────────────────────────────────────────┐
                  │             GATEWAY 2: CENTER            │
                  │         STM32 Core + HSE Crystal         │
                  │       Ultra Low-Noise LDO + SWD          │
                  │   8-Channel Scope Test Points (TP1-TP8)  │
                  └──────────┬───────────────────┬───────────┘
                             │                   │
            ┌────────────────┘                   └────────────────┐
            ▼                                                     ▼
┌───────────────────────────────────────┐ ┌───────────────────────────────────────┐
│     GATEWAY 3: SOUTH-WEST (فرستنده)    │ │      GATEWAY 4: SOUTH-EAST (گیرنده)   │
│ TX_PWM_OUT (5-15kHz) + TX_EN + ISENSE │ │ RX_BLANK_TRIG + ANALOG_RX_IN + AGND   │
└───────────────────────────────────────┘ └───────────────────────────────────────┘
```

## ۳. تعریف سیگنال‌ها و رجیسترهای درگاه‌ها

### ۳.۱. درگاه ۱: شمال (North — ارتباط با Raspberry Pi 5)
- **پروتکل UART با DMA (Circular Buffer):** دریافت پکت‌های تنظیم فرکانس و دیوتی‌سیکل بدون درگیر کردن CPU.
- **پروتکل SPI کمکی:** ارسال دسته‌ای (Burst) نمونه‌های سریع ADC به رزبری‌پای ۵.
- **پین وقفه وضعیت (`IRQ_DATA_READY`):** اعلام پایان پردازش یا ارسال تله‌متری جدید.

### ۳.۲. درگاه ۲: مرکز (Center — امکانات هسته و نقاط تست اسیلوسکوپ)
- **کریستال دقیق خارجی (HSE):** فرکانس ۱۶ یا ۲۵ مگاهرتز با انحراف دمایی بسیار ناچیز.
- **نقاط تست اختصاصی اسیلوسکوپ ۸ کاناله USB (Test Points):**
  - `TP1`: پالس PWM خروجی به گیت ماسفت
  - `TP2`: پالس تحریک بلنکینگ گیرنده (RX Blanking)
  - `TP3`: خط سریال UART_RX (دریافت دستورات)
  - `TP4`: خط سریال UART_TX (ارسال وضعیت)
  - `TP5`: ورودی سنسور جریان فرستنده
  - `TP6`: ورودی سیگنال آنالوگ گیرنده
  - `TP7`: تغذیه ۳.۳ ولت پاک آنالوگ (VDDA)
  - `TP8`: زمین مرجع (GND)

### ۳.۳. درگاه ۳: جنوب‌غربی (South-West — درگاه فرستنده TX)
- `TX_PWM_OUT`: خروجی تایمر پیشرفته (TIM1 یا HRTIM) با قابلیت تنظیم فرکانس در بازه ۵,۰۰۰ تا ۱۵,۰۰۰ هرتز.
- `TX_ENABLE`: کلید فعال‌سازی سخت‌افزاری طبقه قدرت با قابلیت فیل‌سیف خودکار.
- `CURRENT_SENSE_IN`: ورودی مانیتورینگ جریان برای جلوگیری از اشباع کویل یا سوختن ماسفت.

### ۳.۴. درگاه ۴: جنوب‌شرقی (South-East — درگاه گیرنده RX)
- `RX_BLANK_TRIG`: پالس فوق‌سریع قطع ورودی گیرنده پیش و حین شلیک پالس TX جهت حفاظت از آپ‌امپ‌های کم‌نویز.
- `ANALOG_RX_IN`: ورودی سیگنال تضعیف و فیلتر شده جریان‌های گردابی فلز به پین ADC با سرعت بالا.
- `AGND`: زمین ایزوله و شیلد شده بخش آنالوگ.

## ۴. ایمنی سخت‌افزاری (Fail-Safe Watchdog)
در صورتی که ارتباط با رزبری‌پای بیش از ۱ ثانیه قطع شود، STM32 موظف است پالس `TX_PWM_OUT` را سریعاً Low کرده و کویل را خاموش کند.
